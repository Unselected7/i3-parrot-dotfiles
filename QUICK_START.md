# 🚀 Quick Start Guide

## Installation auf frischem Parrot OS

```bash
# 1. Repo clonen
git clone https://github.com/USERNAME/i3-parrot-dotfiles.git
cd i3-parrot-dotfiles

# 2. Installieren (installiert auch i3!)
chmod +x install.sh
./install.sh

# 3. Logout & Login
# Wähle "i3" als Window Manager

# Fertig! 🎉
```

## Erste Schritte in i3

| Keybinding | Aktion |
|------------|--------|
| `Super+Return` | Terminal öffnen |
| `Super+D` | App Launcher (Rofi) |
| `Super+M` | i3 Control Center |
| `Super+W` | Fenster schließen |

## Theme wechseln

```bash
# Per Tastatur
Super+Shift+Y  # Nächstes Theme

# Per Menu
Super+M → Themes → Auswahl
```
